# This project has moved

This was my old personal site, built from the HTML5UP "Editorial" template. It's now retired
in favour of a self-hosted version at **[george-hs.duckdns.org](https://george-hs.duckdns.org)**,
running on a Raspberry Pi with Node.js, PostgreSQL, Docker, and nginx.

Every address under `g323hs.github.io/website/` redirects to the home page of the new site: `index.html`
handles the root, and `404.html` handles every other path.

The old site's files are still in this repository's git history.
